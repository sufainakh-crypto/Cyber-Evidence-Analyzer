Cyber Evidence Analyzer

Digital Forensics & Cyber Threat Intelligence

Cyber Evidence Analyzer is a web-based cybersecurity application designed to simplify basic threat analysis and digital evidence management. It allows users to analyze suspicious URLs, IP addresses, and domains, identify potential risks, and organize investigation records.

✨ Key Features

- Threat Analysis: Analyze suspicious URLs, IP addresses, and domains.
- Risk Assessment: Display risk scores and LOW, MEDIUM, or HIGH risk levels.
- Evidence Management: Generate unique Evidence IDs and manage analysis records.
- Incident Reporting: Support the preparation of structured cyber incident reports.
- Threat Intelligence: Optional integration with external security services.

Technologies Used

- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Database: SQLite
- Version Control: Git and GitHub

 Project Objective

To provide a simple, user-friendly platform that combines basic cyber threat analysis, digital evidence organization, and incident reporting in one place.

Future Scope

Case-based investigations, evidence integrity verification, enhanced threat intelligence, and downloadable PDF reports.
